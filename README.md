# Welp, Another Mission! (WAM)

Godot 4 を使って制作する脱力系サバイバル探索ゲームのプロジェクトです。

## プロジェクト構成

- `project.godot` – Godot プロジェクト設定ファイル
- `scenes/main.tscn` – 仮メインシーン。今後の開発で拠点やフィールドへ拡張予定
- `scripts/Main.gd` – メインシーン制御用スクリプト

## 使い方

1. Godot 4 エディタでこのディレクトリを開きます。
2. `Main` シーンを実行すると、仮 UI とログ出力が確認できます。
3. 今後のステップでゲームロジックやアセットを追加していきます。

## 次のステップ候補

- 拠点と出撃フローを表現する UI スケッチを追加
- 基本移動を行う仮プレイヤーを実装
- フィールド生成のプロトタイプを作成

プロジェクトのコンセプト: 「また任務かよ…」とぼやきながらも惑星探索へ出撃を繰り返す体験を目指します。
